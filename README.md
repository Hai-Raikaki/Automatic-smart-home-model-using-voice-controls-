<h1 style="text-align: center;">🏠 Group project: Automatic smart home model using voice controls. 📱😮</h1>

- Course: Introduction to Electrical Engineering

- Group size: 4

- My role: develop, fix the code and test the program with the complete model

- Project duration: Dec 2019 - Jan 2020

<h2>Components</h2>

- Smart phone: connecting to Internet help to transfer voice to Adafruit.

- Chip mcu esp8266: transferring code to devices.

- Servo: moving the door.

- Google assistant: transfer voice to Adafruit make devices working.

- Adafuit: support control devices.

- 3 leds
